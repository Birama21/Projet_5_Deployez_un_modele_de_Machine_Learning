# 🚀 Futurisys - API Machine Learning

Bienvenue dans la documentation du projet **Futurisys**.

Ce projet consiste à déployer un modèle de Machine Learning capable de prédire le turnover des employés via une API REST.

---

## 🎯 Objectif

Mettre en production un modèle ML complet avec :

- API FastAPI
- Modèle de classification
- Base de données PostgreSQL
- Conteneurisation Docker
- CI/CD avec GitHub Actions
- Déploiement sur Hugging Face Spaces

---

## ⚙️ Stack technique

- Python
- FastAPI
- Scikit-learn
- Pandas
- PostgreSQL
- Docker
- GitHub Actions
- Hugging Face Spaces

---
